CyberForensics Toolkit - Reports Directory
==========================================

This directory contains all forensic reports generated by the toolkit.

Reports are automatically saved here when you use any of the analysis tools:
- IP Analysis Reports
- Network Traffic Analysis (PCAP)
- Malware Analysis Reports
- Hash Cracking Results
- Email Forensics Reports
- OSINT Investigation Reports
- File Recovery Reports
- Evidence Correlation Reports

Access Methods:
1. Web Portal: http://localhost:5000/reports
2. Direct File Access: http://localhost:8080/reports
3. File System: Check this directory in your project folder

Report Formats:
- HTML (Interactive reports with visualizations)
- JSON (Machine-readable data)
- CSV (Spreadsheet-compatible)
- TXT (Plain text logs)

Note: When you first start the toolkit, this directory will be empty.
Reports will appear here after you run analyses.

Generated reports are named with timestamps for easy identification.
Example: network_analysis_20260109_143052.html
